How it works

One conversation, three moves

01

Describe

Type a game idea — a room, a race, a circuit board. The server asks the model for a structured game document, validates it against the schema and sanity-checks it before anything runs.

02

Play

A deterministic TypeScript engine interprets that document: WASD moves, walls collide, switches fire, checkpoints count. Click parts in inspect scenes for their details.

03

Reshape by talking

“Add a second guard”, “raise the platforms”, “make the door open on a pressure plate” — edits arrive as JSON patches, re-validated before they touch the running scene.

The kits

Seven kinds of world, one pipeline

The same generate → validate → play loop; the kit only changes what the scene is made of. Every screenshot below is a real generation captured from the studio.

Open World

A large, walkable world from one prompt: terrain, trees, villages, wildlife and characters built from jointed parts — plus on-screen buttons, a toggle and a slider that spawn and change things live.

Machine

A jointed five-axis arm built from labeled parts. Drag the joint sliders and the whole chain sweeps with real forward kinematics.

Drive

Chase-camera vehicles on a closed course: throttle and steering, ordered checkpoints, speed, lap and timer HUD.

Walkthrough

First-person interiors: a house with doors that slide open, lamps that toggle, and walls that actually stop you.

Inspect

Click-to-learn assemblies like a 3D PCB: silkscreen labels, per-component info panels, camera focus on the first click.

Game

Win and lose archetypes — collect-a-thon, switch puzzle, platform course, stealth chase — with objectives, hazards and rules.

Explore

Atmospheric free-roam scenes with no objectives and no win state — a clearing, a campfire, ambient light.

Reliability

13/13 generated documents usable in the 2026-10-15 live kit evaluation
10/10 judge-style prompts passed on the first iteration, zero repairs
814 automated tests across engine, renderer, server and web

Every generated document is schema-validated and sanity-checked server-side before the browser sees it, and the committed kit fixtures are replayed offline — click rules, door interact, race win path, world spawn buttons. Generated content is data-validated, not hand-authored.
